# Voice

How jobship sounds. Terms follow [GLOSSARY.md](../../GLOSSARY.md). Name and slogan come from the decisions table in [README.md](README.md); audience, personality and the avoid list come from [brief.md](brief.md). The lines to reuse are in [copy.md](copy.md).

## In one line

jobship speaks like a precise, calm colleague who shows the work and leaves the decision to you.

## We are / we are not

| We are                                                     | We are not                                    |
| ---------------------------------------------------------- | --------------------------------------------- |
| Precise: one claim, one fact, one file that backs it       | Hype: no superlatives, no "revolutionary"     |
| Calm: the search is hard enough without pressure           | Urgent: no fear of the market, no countdowns  |
| Trustworthy: we claim no more than the CLI does today      | Promising: no interviews, offers or hit rates |
| Plain: short sentences and the glossary's words            | Clever: no puns, no jargon without a gloss    |
| On the human's side: you decide and you press Submit       | Autonomous: the tool never applies or sends   |
| Auditable: every claim can be read back from the event log | Magic: nothing happens that code cannot show  |

## Tone by context

| Context                        | Tone                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| README, GitHub About, listings | Plain and factual. Say what it does in one sentence, then the hand-off: you press Submit.   |
| Slogan and cover               | Short and confident, never loud. The brand line carries it; no exclamation marks.           |
| CLI help and output            | Terse and literal. Name the command, the flag or the field. No decoration, no emoji.        |
| Errors and refusals            | Say what happened, why, and what to do next. Never blame the human. Fail closed and say so. |
| Guard denials                  | Direct and neutral: this action submits or sends, so the human does it.                     |
| Docs and guides                | Task first, steps numbered, one idea per sentence. Link to the glossary for terms.          |
| Release notes and changelog    | What changed and what it means for the data dir. No marketing.                              |
| Social and community posts     | Same as README. Show a real command or output. No growth language.                          |

No exclamation marks anywhere. No pressure, urgency or fear about the job market.

## Terminology

Use the glossary terms and capitalise them as the glossary does. Where the glossary lists an avoided word, do not use it in copy.

| Say             | Not                         |
| --------------- | --------------------------- |
| Posting         | job, offer, listing         |
| Source          | portal, provider            |
| Sweep           | scan, crawl                 |
| Lead            | opportunity, candidate job  |
| Application     | job, deal                   |
| Ledger          | seen list, cache            |
| Event           | log entry, update           |
| Profile         | settings, preferences       |
| Fact bank       | profile data, resume data   |
| Needs-you queue | inbox, todo                 |
| Tailored CV     | optimised resume, AI resume |

Other fixed forms: "jobship" is lowercase, including at the start of a sentence when it names the command or package. "Claude Code" and "Anthropic" are written as their owners write them.

## Language to avoid

- Words: "AI magic", "auto-apply", "autonomous", "supercharge", "land your dream job", "while you sleep", and any hunting or weapon language (hunt, target, crosshairs, arrow, trap, arsenal).
- Verbs that make the tool the actor of an irreversible move: applies, submits, sends for you.
- Outcome promises: interviews, offers, "get hired faster", "more callbacks".
- Numbers the CLI does not back: speed, hit rate, adoption, "10x", counts of jobs found.
- "First", "only", "best" and other claims of rank.
- Urgency and fear: "don't miss out", "the market is brutal", "before it is too late".
- Exclamation marks, emoji in copy, and hype adjectives.

## Relation to Anthropic

jobship runs on Claude Code and copy may say so descriptively, for example "plugin for Claude Code". It is an independent project. Every public surface that introduces the project carries the notice `jobship is not affiliated with or endorsed by Anthropic.` verbatim. The name, mark, palette and any mascot stay separate from Claude's identity: no Claude orange or clay, no sparks or starbursts, and no wording that implies Anthropic made, approved or supports jobship.
